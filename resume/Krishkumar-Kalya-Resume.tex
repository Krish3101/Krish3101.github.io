{https://github.com/Krish3101/disputeledger}
{TypeScript, Express, better-sqlite3, Zod}

\begin{itemize}

\resumeItem{
Built a dispute tracking system for supply chain partners: disputes are raised with evidence attached, arbiters resolve them, and every action is recorded on an append-only event log.

\resumeItem{
Made the log tamper-evident by chaining events with SHA-256 --- each event stores the previous event's hash, so verification recomputes the chain and a row edited directly in the database breaks the link instead of passing unnoticed.
